# 1. Design Philosophy

TWO is built using the **CEDAR Design Thinking Framework**, a human-centered product methodology focused on creating meaningful digital experiences through strategic design decisions.

The design system was created to support clarity, trust, speed, usability, and financial confidence for freelancers, creators, vendors, and SMEs.

The visual and interaction language prioritizes:

- Simplicity
- Professional trust
- Workflow efficiency
- Accessibility
- Financial clarity
- Seamless task completion

---

## Built Using CEDAR

### C — Context

The billing experience for SMEs is often fragmented and inefficient.

The interface must reduce financial workflow friction and simplify documentation.

Design implication:

- Minimal interface complexity
- Clear task hierarchy
- Fast completion pathways

---

### E — Empathy

Users are often non-technical and time-sensitive.

The product must feel intuitive immediately.

Design implication:

- Familiar workflows
- Clear language
- Reduced cognitive load
- Guided interactions

---

### D — Decisions

Design decisions prioritize:

- Speed over unnecessary visual complexity
- Actionable layouts
- Clear conversion paths
- Strong status visibility

---

### A — Architecture

The interface is structured around logical workflow progression:

Authentication  
→ Dashboard  
→ Invoice Creation  
→ Tracking  
→ Receipt Conversion  
→ Records Management

---

### R — Responsibility

The design must ensure:

- Accessibility
- Trustworthiness
- Responsive consistency
- Inclusive interaction standards

---
